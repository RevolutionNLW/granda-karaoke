## Changes

- Key and Tempo can be prepared on a selected song before playback, saved at once through
  the existing song settings.
- Play starts the selected song when nothing is playing (library: as Sing This Song;
  playlist: as the playlist's Play, so Autoplay carries on from it).
- While a song plays or is paused, Key, Tempo and Play stay with it whatever is selected.
- Now Playing says "Nothing playing" at start-up, after Stop and after a song ends; Autoplay
  replaces it with the next song.
- The library and playlist KEY columns and Now Playing show the same original → current key
  ("C → D"): a key set by hand, else a confidently detected one, else nothing.
- Long playlists: no data cap existed (tested to 500 songs); the scroll bars are now clearly
  visible (more than 3:1 contrast), which was why later songs seemed missing.

Known limitation: a remembered Key/Tempo shown for a song can be stale if its file was
replaced, moved or exactly duplicated, until its first Key/Tempo change or playback reads
the real file. Playback and saving always use the song's own files.
